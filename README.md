# 地学クリノメーター (Geological Clinometer for Android)

地質調査・地学実習・フィールドワークにおいて、地層の**走向（Strike）**と**傾斜（Dip）**を高精度かつ直感的に測定・記録できるオープンソースのAndroidアプリケーションです。

---

## 主な機能と特徴

### 1. 2つの測定モード
- **面測定（背面密着モード）[推奨]**
  - スマホの背面全体を地層面（層理面）にペタッと密着させるだけで、内部の3軸加速度・地磁気センサーから走向と最大傾斜角を一度に自動計算します。
  - **スマホの向きは自由**: 3次元法線ベクトルから直接幾何計算するため、縦向き・横向き・斜めなど、どの角度で構えても同じ測定値が得られます。
- **側面測定（伝統式モード）**
  - アナログのクリノメーターと同じ手順で、スマホの長辺側面を地層に当てて測定します。

### 2. 伝統的なクリノコンパス盤（E/W逆転目盛）
- 日本式クリノメーター特有の「東西（E/W）逆転目盛り」を再現。磁針が指す方角をそのまま読むだけで走向方位が直読できます。
- ワンタップで通常の方位磁針（標準コンパス盤）と切り替え可能です。

### 3. 多彩な表記形式に対応
- **日本式（四方位角表記）**: 例 `N 30° E  45° SE`
- **右手則 (Right-Hand Rule: RHR)**: 例 `030° / 45°`（国際地質学規格）
- **Dip / Dip Direction**: 例 `45° / 120°`

### 4. 野外調査を支える実践的な機能
- **音量キーでHOLD & バイブレーション**: 
  - 見上げ面やオーバーハング、狭い隙間で画面が見えない場合でも、音量ボタン（Up/Down）を押すことで測定値を固定。手元の感触でロック状態が分かります。
- **デジタル野帳（データ記録 & CSV出力）**:
  - 露頭番号や岩相メモ（例: `Loc.1 砂岩泥岩互層`）を添えて保存。ワンタップでCSV形式でクリップボードへコピー可能。
- **真北・磁気偏角補正**:
  - 日本各地（沖縄 -5.5°、東京 -7.8°、札幌 -9.5° など）の偏角プリセットを内蔵。
- **机上シミュレーションモード**:
  - 授業やテスト、机上検証用に、スライダーで走向・傾斜・方位を自由にシミュレート可能。
- **充実した使い方ガイド（立体図解入り）**:
  - 画面右上の「？」アイコンから、電波の届かない山奥でもオフラインで読める図解ヘルプシートを搭載。

## インストール方法

1. [GitHub Releases](../../releases) ページにアクセスします。
2. 最新リリースの `app-release.apk` をAndroidスマートフォンにダウンロードします。
3. ダウンロードしたAPKファイルを開き、画面の指示に従ってインストールしてください。（※「不明なアプリのインストール」の許可が必要です）

---

## 動作要件

- **OS**: Android 8.0 (API レベル 26) 以上
- **ハードウェア**: 3軸加速度センサーおよび地磁気（電子コンパス）センサーを搭載したAndroid端末

---

## 開発・ビルド方法

### 前提条件
- JDK 17 以上
- Android SDK (API 35, Build-Tools 35.0.0 以上)

### ビルド手順
```bash
# リポジトリのクローン
git clone https://github.com/JustCat3456/clinometer-app.git
cd clinometer-app

# デバッグビルドの実行 & 端末インストール
./gradlew installDebug

# リリースAPKの生成
./gradlew assembleRelease
# 生成先: app/build/outputs/apk/release/app-release.apk
```
